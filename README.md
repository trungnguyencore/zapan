# ZaPan v2 Workspace

ZaPan v2 is a greenfield Japanese-learning application under active development.

## Start here
1. `PROJECT_PROGRESS.md` — verified current state and next action.
2. `implementation.md` — master implementation specification.
3. `WEB_ROADMAP.md` — five-phase engineering/product roadmap.
4. `LEARNING_ROADMAP.md` — learner journey from Kana toward N5/N4/N3.
5. `PROJECT_EVIDENCE.md` — actual verification results.
6. `PROJECT_DECISIONS.md` — architecture decisions and lessons.
7. `docs/` — architecture, UX, Firebase and testing plans.

## Hard boundary
All ZaPan v2 implementation work stays inside this workspace unless the owner explicitly approves otherwise.
Legacy Japanese/ZaPan folders are read-only reference material and are not the codebase for v2.

## Application

Current Phase 1 is foundation only; cloud sync and learning content are not yet production features.
